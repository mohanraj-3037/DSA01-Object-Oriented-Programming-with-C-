# DSA01 – Assignment 1: Namma Metro Smart-Card Fare System

## Phase 1 status
- Task 01: OOP problem analysis and UML class diagram.
- Task 02: C++ tokens, `constexpr` constants and `enum class` demonstration.
- Task 03: Data type sizes, integer-paise representation, limits and daily revenue range.

## Compiler
Use a C++17 compiler such as g++.

## Compile and run
From the repository root:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic Task02/constants.cpp -o task02
./task02

g++ -std=c++17 -Wall -Wextra -pedantic Task03/datatypes.cpp -o task03
./task03
```

On Windows PowerShell, run the generated executable as `./task02.exe` or `./task03.exe`.

## Important assignment note
